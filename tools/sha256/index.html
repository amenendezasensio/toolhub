¿Qué es SHA-256?

SHA-256 es un algoritmo criptográfico perteneciente a la familia SHA-2 que transforma cualquier texto en un hash único de 256 bits (64 caracteres hexadecimales).

¿Para qué se utiliza?

Se utiliza para verificar la integridad de archivos, almacenar contraseñas de forma segura (junto con técnicas adicionales), firmar datos y proteger información en multitud de aplicaciones.

¿Es reversible?

No. SHA-256 es una función hash unidireccional: a partir del resultado no es posible recuperar el texto original mediante el algoritmo.
